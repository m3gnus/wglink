# Headless workflow status

Waveguide Generator currently sends a Fusion model to Waveguide Generator (WG) for interactive setup and solving. The WG Metal pipeline commands previously documented here have moved out of this repository with the frozen legacy fallback; commands under this repository's former `scripts/` path no longer exist.

For the maintained path, install WG with its Waveguide Generator Fusion add-in, press **Send** in Fusion, then configure and solve the imported model in WG. A supported headless Solve command for the add-in is planned, but has not been delivered yet. Until then, use WG's supported interface for the job so its setup, ownership and run history remain consistent.
